# Pet Classification

Pet image classification using machine learning and computer vision.

## Project Description

This project focuses on classifying pet images using a machine learning approach.

The dataset is obtained from Kaggle and processed using Python in a Jupyter Notebook.

## Dataset

The project uses the Oxford-IIIT Pet Dataset.

## Technologies Used

- Python
- Jupyter Notebook
- Kaggle API
- Machine Learning
- Computer Vision
